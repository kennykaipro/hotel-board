投标参与方法

通用路径，适用于本页全部盯标项目
01
公共资源交易平台盯公告
全国平台 ggzy.gov.cn + 各省市公共资源交易网，按「项目名 / 业主名」检索招标公告。
02
标讯平台订阅关键词
招标网 / 采招网 / 火标网按「项目名 + 弱电 / 智能化 / AV」订阅，第一时间收标。
03
盯工程 / 企查查找甲方
cbi360 盯工程、企查查 / 天眼查查业主、总包、设计院与经办人联系方式。
04
设计院上游介入
对接酒店施工图设计院（如华东院），锁定弱电 / AV 点位设计，早期送样入围。
05
酒管供应商名录（MBE）
万豪 / 希尔顿 / 洲际 / 雅高等有认可供应商名录，入库才有投标资格；同时联系施工总包做专业分包入围。
